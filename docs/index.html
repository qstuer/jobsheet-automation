Jobsheet Automation

A personal workflow operated by its owner to organize authorized service jobsheets.

The application reads scanned jobsheets from the owner's configured Google Drive folders, separates service records, checks equipment and visit details against the owner's Asana workspace, and archives matched PDFs to the configured OneDrive destination. It records processing status and can notify the owner about records needing attention.

This page describes the application. Account access is granted separately through Google OAuth. The workflow is intended for the owner's use and is not a public file-processing service.
