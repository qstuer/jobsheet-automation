Jobsheet Automation: privacy and data handling

Updated 19 November 2026. This page describes the owner's personal service-record filing workflow.

Google account access and purpose

With the owner's authorization, the application lists and downloads jobsheets in configured Google Drive folders, creates split PDFs and processing reports there, and moves or trashes source records according to the filing workflow. Google Drive access is used for these owner-directed operations.

Processing and connected services

The workflow runs locally or in the owner's GitHub Actions environment. Jobsheet images are sent to the configured vision provider for OCR; the production configuration uses NVIDIA. Extracted equipment and visit details are checked against the owner's Asana workspace. Matched PDFs are saved to the configured Microsoft OneDrive destination. The workflow may append a missing short service note to the confirmed Asana task and notify the owner, according to the owner's configured rules. These services process information under their own applicable policies.

Storage and access

Source scans, the equipment index and processing reports are kept in the configured private storage. Authorized PDFs remain in the selected archive. Credentials are held in local private configuration or encrypted GitHub Actions secrets. This public site contains application documentation, not a jobsheet collection or an upload form. It does not use analytics or advertising scripts.

Retention and control

Scans needing review remain in the configured source or review folders. Successfully processed sources follow the owner's filing rules; normal Google Drive deletions go to Trash. Archived files follow the owner's retention choices. The owner can revoke the application's access in Google Account settings and disable its automation. Revoking access stops future authorized access; it does not automatically delete existing archived records.

Contact

Contact the application owner through the project repository. Do not attach private records or credentials to public issues.
